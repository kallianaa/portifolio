# 💻 Portfólio Pessoal - Kalliana Glaeser

Este é o repositório do meu portfólio pessoal, desenvolvido para apresentar minhas informações profissionais, minhas habilidades e as tecnologias com as quais trabalho e estudo.

🔗 **Acesse o site online:** [kallianaa.github.io/portifolio](https://kallianaa.github.io/portifolio/)

---

## 📌 Sobre o Projeto

O site foi construído com foco em organização de código, acessibilidade e design responsivo (adaptado para celulares, tablets e computadores).

Ele conta com:
- Apresentação profissional e foco de carreira.
- Seção com ícones das principais tecnologias estudadas.
- Links diretos para minhas redes profissionais (LinkedIn e GitHub).
- Layout responsivo utilizando CSS Flexbox e Media Queries.

---

## 🛠️ Tecnologias Utilizadas

- **HTML5:** Estrutura e marcação semântica.
- **CSS3:** Estilização, variáveis de layout, Flexbox e regras de responsividade.
- **JavaScript:** Atualização automática do ano no rodapé.
- **Font Awesome:** Ícones das redes sociais.
- **Google Fonts:** Tipografia (Fonte Roboto).
- **GitHub Pages:** Hospedagem gratuita da página.
